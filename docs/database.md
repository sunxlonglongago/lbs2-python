# Data dictionary

Generated by `server/src/tools/export_docs.py` from `server/src/schema.py`; do not edit it by hand - rerun `make docs` after a schema change.

Table and column names follow the original LBS^2 database (see NOTICE). The declared type is the app level type: SQLite stores an affinity, so a declared `TEXT(255)` still lands in a `TEXT` column, and the length is enforced by the application.

## Declared type to SQLite

| Declared | SQLite | Notes |
|---|---|---|
| YESNO | INTEGER | 0/1 |
| BYTE | INTEGER | small integer |
| INTEGER / LONG | INTEGER | autonumber keys use INTEGER PRIMARY KEY AUTOINCREMENT |
| DATETIME | TEXT | `YYYY-MM-DD HH:MM:SS`, local time |
| TEXT(n) | TEXT | n is the maximum character count |
| MEMO | TEXT | unlimited |

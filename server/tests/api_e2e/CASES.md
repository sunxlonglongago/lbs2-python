# Full business API E2E case list

Generated by `server/tests/api_e2e/runner.py` on every run (`make test_api_full`);
do not edit by hand. The scenarios live in `server/tests/api_e2e/scenarios/`.

| Scenario | Case | Description |
|---|---|---|
| auth | `auth.me` | anonymous and logged-in /api/auth/me |
| auth | `auth.login` | administrator logs in and gets the rights block |
| auth | `auth.bad_password` | a wrong password returns login_fail |
| auth | `auth.login_ban` | the fifth failure in one session triggers the temporary ban |
| auth | `auth.register` | register a new user and log in automatically |
| auth | `auth.register_duplicate` | a duplicate user name is refused |
| auth | `auth.logout` | the session is gone after logout |
| articles | `articles.list` | the index list returns the seed article and paging data |
| articles | `articles.detail` | the detail returns body, merged comments and the view counter |
| articles | `articles.create` | an administrator creates an article; [separator] sets has_more on the list |
| articles | `articles.visibility` | a private article is 404 for guests and visible to the administrator |
| articles | `articles.create_forbidden` | a regular user without post rights is refused |
| articles | `articles.edit_forbidden` | a regular user cannot edit somebody else's article |
| articles | `articles.delete` | a deleted article is no longer reachable |
| comments | `comments.guest_requires_name` | a guest without a name is refused |
| comments | `comments.guest` | a guest posts under a display name |
| comments | `comments.member` | a logged-in user posts a hidden comment |
| comments | `comments.visibility` | comments show up in the article detail with the hidden flag |
| comments | `comments.validation` | empty and oversized comments are refused |
| comments | `comments.wordfilter` | a word filter hit is replaced as configured |
| comments | `comments.flood` | posting again too soon is refused |
| guestbook | `guestbook.list` | the guestbook list is public |
| guestbook | `guestbook.post` | a guest signs the guestbook |
| guestbook | `guestbook.edit` | an administrator edits an entry and writes a reply |
| guestbook | `guestbook.delete` | an administrator deletes an entry |
| trackback | `trackback.list` | the trackback list is public |
| trackback | `trackback.ping` | an external ping is accepted with error 0 |
| trackback | `trackback.duplicate` | a ping with the same title and excerpt is de-duplicated |
| trackback | `trackback.invalid` | missing parameters or a missing article return an error |
| trackback | `trackback.delete` | an administrator deletes a trackback |
| users | `users.list` | the user list is public but hides emails |
| users | `users.profile` | the profile returns the group name and rights |
| users | `users.update_wrong_password` | a wrong current password blocks the save |
| users | `users.update` | the new password works after the change |
| users | `users.group_change` | changing the group changes the rights |
| users | `users.delete_last_admin` | deleting the last administrator is refused |
| admin | `admin.gate` | non-admins and sessions without the second login are blocked |
| admin | `admin.login` | admin login: wrong password refused, right password accepted |
| admin | `admin.settings` | settings follow the original rules (exclusive bounds, empty strings skipped) |
| admin | `admin.categories` | rename and add categories |
| admin | `admin.groups` | add a user group and check the rights digits |
| admin | `admin.database` | backup and compact |
| admin | `admin.misc` | recompute counters and clean up |
| admin | `admin.site_state` | close and open the site |
| feeds | `feeds.site` | site metadata carries theme paths, switches, sidebar and announcement |
| feeds | `feeds.lang` | the language pack covers the keys the frontend uses |
| feeds | `feeds.rss` | the article RSS is well formed |
| feeds | `feeds.comment_rss` | the comment RSS filters by article |
| feeds | `feeds.js` | type=js emits a document.write snippet |
| feeds | `feeds.categories` | the category and calendar endpoints |
| upload | `upload.limits` | the upload limits are readable |
| upload | `upload.reject_type` | a non-whitelisted extension is refused |
| upload | `upload.accept` | a whitelisted image uploads and yields a UBB tag |
| upload | `upload.guest` | anonymous uploads are refused |
| urls | `urls.root` | the root redirects to default.asp |
| urls | `urls.pages` | every page entry point is served as .asp |
| urls | `urls.api_suffix` | API paths behave the same with and without .asp |
| urls | `urls.api_items` | API paths with parameters accept .asp too |
| urls | `urls.html_redirect` | .html pages 302 to their .asp form |
| urls | `urls.upload` | upload.asp serves the upload page, upload.html redirects to it |
| urls | `urls.no_html_pages` | no .html page URLs are exposed |
| urls | `urls.panel_wiring` | sidebar element ids line up with the layout.js fill code |
| urls | `urls.feed` | feed.asp and trackback.asp work |
